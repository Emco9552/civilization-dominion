How it works

  • Both players open this game and go to Multiplayer.
  • The host creates a room and shares the 5-letter code.
  • Everyone picks a different country on the map.
  • The host starts the game — unclaimed nations stay AI.
  • Realistic Mode only: the world advances every 3 seconds, and the host's simulation is the official one for everybody.
  • Random events and Sandbox are disabled in multiplayer.
  • Needs an internet connection (peer-to-peer with a free broker). Players do not need to be on the same Wi-Fi — friends can join from anywhere.
  • Everyone must run the same game version (shown above) — a different build is refused with a clear message. If joining fails, press 📋 Export Debug Report and send the file to the host.
